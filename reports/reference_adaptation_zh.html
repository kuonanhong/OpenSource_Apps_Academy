可移植的具體設計

實際原始碼模式 對 Open Lab 的具體改法
兩個參考的根 index.html 有立即導向、手動入口及完整解壓提示；JS 導向保留 hash，公開 HuaTuo 也保留 query。 根入口保留 location.search 與 location.hash，同時留下可點入口。以「開始閱讀」「開啟工具」「使用指南」為第一層，不要求學員先看安裝術語。
華佗 bootstrap.js 逐一載入 classic scripts，載入失敗會顯示檔名與修復方法。 保留 classic/IIFE 入口與 defer 資料，加入可讀的載入失敗面板；避免只留下轉圈動畫。
華佗 course-player.js:14–26：HTTP 模式取 JSON；file:// 模式透過 script 載入該學科 JS 資料。 正文採按篇載入的 window.OPENLAB_PAPERS[id] JS 備援。HTTP 仍可用 JSON；不要為雙擊載入全部 719 篇完整正文。
馬蓋先離線模式載入 offline-data.js、多份 offline-data-NN.js、offline-runtime.js，再載入預建 bundle。 借鏡預建與資料包形式，但不要整包照搬數百 MB。閱讀所需資料預載；正文與大型工具按需載入。
華佗課程先呈現工作台，之後才展開目標、操作、觀察、失效與驗收；有上一步／下一步、測驗解釋及來源。 每個工具頁固定「選檔／載入例子 → 執行 → 檢視結果 → 匯出」，說明置於同頁。每篇論文固定「問題 → 先修 → 假設 → 主張 → 證明路線 → 小例子 → 限制 → 延伸」。
華佗完成條件是實作與測驗都通過；進度與下一步狀態一直可見。 工具成功應根據真實函式／API 回傳；閱讀完成、計算成功、證明已核驗分開記錄。不要因按下按鈕就記為成功。
桌面側欄、手機底部導覽、搜尋、明顯語言切換；AI 師傅是可選面板。 手機保留主要動作與輸出，不把工具藏在長文章底部。中文／英文內容與機器翻譯覆蓋分開標示。
華佗語音嘗試預設聲音、等待 voiceschanged，以真正的 onstart／onplaying 更新狀態；可選 /api/tts。 「試聽／播放／停止／重試」都應可見；聲音清單暫時為空不直接宣告失敗。未連接 TTS 時仍能閱讀文字。
華佗 Service Worker 只快取明列的公開 shell；避開 API、私人目錄及受保護課程。 PWA 快取只限公開閱讀資產；不快取 token、使用者檔案或 AI 回覆。不能把首頁可離線誤寫為全部正文及模型已離線。

舊 Open Lab 的雙擊問題：可確定與不可確定部分

檢視時根入口只是導向 dist/index.html；實際首頁已經使用 classic scripts，並以 JS 形式附帶目錄、中文摘要與學習路徑。因此，不能把整個舊版的問題一概歸因為 ES modules，亦未重現「所有瀏覽器首頁空白」。確定的阻礙是：

  1. assets/app.js 的完整正文按鈕仍使用 fetch() 讀取逐篇 JSON；失敗後才提示啟動本機服務。
  2. assets/tools.js 的 math.js 工作執行緒明確拒絕 file://。部分其他工具也有相同服務需求。
  3. api() 在 file:// 下拒絕執行；GitHub Pages 上的 /api/* 也沒有 Python 後端。
  4. 根入口的固定 meta refresh 不保留深連結；手機檔案預覽器也不保證像完整瀏覽器一樣執行 JS。

建議常駐顯示「離線閱讀／線上靜態站／本機完整服務」模式與每個工具的可用狀態，在執行前說明差異。需要 Worker 的計算可改為 Blob Worker 並真正測試，或明確引導一鍵啟動器；不要退回主執行緒運算而失去逾時終止。HTML 按鈕不能可靠、通用地直接執行任意本機 shell。

公開交付邊界

  • 完整 ZIP 中約 215.46 MB 是 models/；public/ 約 88.95 MB。公開 HuaTuo tree 全部檔案約 34.06 MB。模型、會員完整內容與私人站長設定不應因「模仿網站」一併搬入新站。
  • 只從新專案的已驗證靜態輸出發布；排除 private/、owner-private/、portable/data/、local-documents/、模型／權重、資料庫、.env*、私鑰、上傳檔與參考 ZIP。不跟隨 symlink。
  • 華佗 tools/export_static.py 會裁掉非免費階段；公開庫 tools/stage_pages.py 又依管理清單和逐檔 SHA-256 建立 Pages artifact。這個「明確清單＋雜湊」模式比整個工作資料夾直接上傳更值得採用。
  • 華佗 LICENSES.md 明列程式與課程文字 MIT；第三方模型／資料另外適用各自授權。API 的 license:null 並不代表沒有授權文件。此次建議重寫互動模式，不複製醫學教材、私密內容或大型資產。

建議驗收

完整解壓後，在兩種桌面瀏覽器以 file:// 開啟根入口、逐篇正文與至少一項不依賴服務的工具；另外用 localhost 與 /REPO/ 子路徑測試所有連結。驗收記錄應分開列出哪些功能在各模式成功，手機語音與模型推論只有真機執行後才能標成已測試。
