Patterns to adapt

Evidence in the references Concrete Open Lab adaptation
Root entry with redirect, manual link and complete-extraction instructions. Preserve query/hash; provide an obvious reading entry and a separate local-service launcher.
Ordered classic-script loader, explicit static/file mode, readable failure message. Keep a built static shell and JS data. Show the failed asset and a recovery action instead of an endless spinner.
HuaTuo loads course JSON over HTTP and a course JS shard under file://. Load one manuscript JS fallback on demand. Do not parse all 719 full texts on startup.
MacGyver has prebuilt bundles and multiple offline-data shards. Reuse the packaging idea, not its hundreds of MB of content.
HuaTuo presents practice first, with objectives, instructions, observations, failures, checks and sources nearby. Tool sequence: choose input/example, run the real engine, inspect output, export. Paper sequence: problem, prerequisites, assumptions, claim, proof outline, example, limitations, research extensions.
Practice and quiz success are separate completion gates. Keep reading progress, successful computation and independently checked proof status separate.
Sidebar, mobile navigation, search and language control remain visible. Keep primary actions accessible on phones. Distinguish authored translation from optional machine translation.
Speech state follows real start/play events and delayed voice discovery. Offer play/test/stop/retry; an initially empty voice list must not immediately block playback. Backend TTS remains optional.
Service Worker caches an explicit public shell list and excludes private/API data. Cache public reading assets only; do not imply that a cached home page includes all papers and model weights.

What the old double-click issue actually establishes

The inspected Open Lab entry redirects to dist/index.html; that page already uses classic scripts and JS copies of its catalogue, translations and learning paths. It would be inaccurate to blame all entry failures on ES modules or claim that every browser showed a blank page.

The confirmed restrictions were the full-text button's JSON fetch, the math Worker’s explicit file:// guard, and local API calls. The root redirect also discarded deep-link state. Static hosting supplies no Python API. Phone file-preview applications may not execute the site like a full browser.

Show a persistent operating mode: offline reading, hosted static site, or local service. Mark a tool’s requirements before execution. A Blob Worker is a possible file-mode adaptation only after a real test; a blocking main-thread fallback would sacrifice timeout termination. A webpage cannot reliably launch arbitrary local shell commands across devices.

Public-export boundary

The complete HuaTuo ZIP contains about 215.46 MB of model assets and 88.95 MB under public/; the public repository’s complete file tree is about 34.06 MB. Do not transplant the full distribution into Open Lab. Publish only a verified generated static export; exclude private/owner files, databases, local documents, models, weights, credentials, uploaded files and reference archives. Reject symlinks.

HuaTuo’s exporter removes non-free course stages. Its public stage_pages.py uses an explicit file list and per-file SHA-256 checks before producing the artifact. This is the strongest deployment pattern to adapt. Its LICENSES.md explicitly licenses project code/course text under MIT; third-party materials retain their own terms. A GitHub API license:null is not a substitute for reading that file. Recommendations here transfer interaction patterns without copying medical content or large assets.

Acceptance should cover a completely extracted package under file://, localhost and a /REPO/ hosting prefix; verify entry links, a full manuscript and a service-free tool. Mobile sound and model inference require their own actual-device checks.
