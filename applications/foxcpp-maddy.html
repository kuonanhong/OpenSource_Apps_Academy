Maddy Mail Server

Maddy Mail Server 是用於郵件服務的應用。

All-in-one mail server that implements SMTP (both MTA and MX) and IMAP. Replaces Postfix, Dovecot, OpenDKIM, OpenSPF, OpenDMARC with single daemon.

GPL-3.0
