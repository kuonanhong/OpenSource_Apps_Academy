dsh-context

透過面板、瀏覽器介面、側欄及命令，檢視 DeepSeek Harness 的上下文組成、用量與變化。可協助理解智能體收到哪些資訊，但不保證模型一定正確運用它們。

Visualizes and inspects DeepSeek Harness context composition, usage and changes through dashboards, browser panels, sidebars and commands. It helps users inspect what enters an agent context without proving that a model will use it correctly.

Apache-2.0
