TencentDB-Agent-Memory

團隊智能體記憶服務，透過管理介面整理對話、可重用技能、文件知識與程式碼圖譜。部署包含多個服務，並需另外配置模型連接。

A team memory service that organizes agent conversations, reusable skills, document knowledge and code graphs with a management interface. Deployment uses multiple services and separately configured model connections.
