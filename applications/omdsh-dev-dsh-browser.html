dsh-browser

透過 Chrome 或 Firefox 擴充功能連接 DeepSeek Harness，使智能體檢視結構化頁面文字、導覽、操作控制項及管理分頁。安裝包含 DSH 橋接與瀏覽器擴充功能，並有主程式版本要求。

Connects DeepSeek Harness to a Chrome or Firefox extension so agents can inspect structured page text, navigate, operate controls and manage tabs. Installation includes both a DSH bridge and a browser extension, with host-version requirements.
