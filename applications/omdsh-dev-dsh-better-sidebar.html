DSH-better-sidebar

為 DeepSeek Harness 加入右側欄與底部工作區，提供檔案管理、Git 檢視、終端及側邊對話。其他插件可透過其側欄服務註冊面板。

Adds a right sidebar and bottom workbench to DeepSeek Harness, including file management, Git views, terminals and side conversations. Other plugins can register panels through its sidebar service.
