pdf-inspector

Rust 函式庫與命令列工具，可分類 PDF、擷取含位置資訊的文字，並把適合的文件轉成 Markdown。文件列有 Python、Node.js 與瀏覽器 WebAssembly 繫結；支援的原生使用端可選擇局部 OCR。

A Rust library and command-line tool that classifies PDFs, extracts positioned text and converts suitable documents to Markdown. Python, Node.js and browser WebAssembly bindings are documented; selective OCR is optional for supported native consumers.
