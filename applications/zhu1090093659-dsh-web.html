dsh-web

DeepSeek Harness 的模組化 Web GUI 擴充套件，整合任務看板、遠端存取、終端、Git worktree、會話搜尋與用量介面。需要已安裝且版本相容的 DSH 主程式。

A modular Web GUI extension suite for DeepSeek Harness with task boards, remote access, terminals, Git worktrees, session search and usage views. It extends an installed DSH host and depends on the compatible host version.

Apache-2.0
