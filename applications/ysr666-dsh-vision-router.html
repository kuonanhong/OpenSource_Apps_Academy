dsh-vision-router

把 DeepSeek Harness 的影像請求路由至圖片問答、定位、裁切、像素差異、色彩檢查與 OCR 工具。外部供應服務的可用性與插件程式授權是不同事項。

Routes image-related requests from DeepSeek Harness to vision tools for question answering, localization, crops, pixel differences, colour inspection and OCR. External provider availability is separate from the plugin code licence.
